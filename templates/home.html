Audit your AI agent's configuration before the agent runs it.

cfgaudit is a static security auditor for the files that configure coding agents: Claude Code settings, hooks, skills and plugins, MCP servers, CLAUDE.md and AGENTS.md, and the configs of Cursor, Codex, Copilot, Gemini CLI and more. It catches unrestricted permissions, hooks that run on every session, unpinned MCP servers, leaked secrets and prompt injection in instruction files. It runs offline as a single binary and never starts an agent.

Install

GitHub Action

- uses: cfgaudit/cfgaudit@v{{.Version}}
  with:
    path: .

Runs the published container image. With format: sarif the findings go to GitHub Code Scanning.

GitLab CI/CD component

include:
  - component: gitlab.com/cfgaudit/cfgaudit/cfgaudit@v{{.Version}}

A second component reports findings in the merge request's Code Quality widget.

Package managers

brew install cfgaudit/tap/cfgaudit
pipx install cfgaudit
go install github.com/cfgaudit/cfgaudit/cmd/cfgaudit@v{{.Version}}

Homebrew, PyPI (also uvx cfgaudit) and the Go toolchain. The PyPI wheels carry the release binary after its checksum and provenance check, with PyPI attestations from the release workflow.

Docker

docker run --rm -v "$PWD:/work" -w /work \
  ghcr.io/cfgaudit/cfgaudit:{{.Version}} .

Signed with cosign, with SLSA provenance and an SBOM.

Binary

curl -sSLO \
  https://github.com/cfgaudit/cfgaudit/releases/download/v{{.Version}}/cfgaudit_{{.Version}}_linux_amd64.tar.gz
tar xzf cfgaudit_{{.Version}}_linux_amd64.tar.gz

Archives for Linux, macOS and Windows on amd64 and arm64 on the release page, with checksums.txt and SLSA provenance. Check a download with gh attestation verify as shown in Verifying a release.

Claude Code plugin

/plugin marketplace add cfgaudit/cfgaudit
/plugin install cfgaudit@cfgaudit

Adds /cfgaudit:scan, /cfgaudit:explain <RULE> and /cfgaudit:init, and hooks that scan after edits to settings.json, CLAUDE.md, .mcp.json or .claude/ and when a session ends. Without a cfgaudit on your PATH it downloads the checksum-verified release binary. Team rollout in the README.

Output formats: text, table, JSON, SARIF and Code Climate, with an example of each. See the README for every option and every agent cfgaudit reads, and Verifying a release to check a download before you run it.
