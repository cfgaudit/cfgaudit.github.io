Performance

How long each release takes to scan the same project: a tree generated from a fixed seed, with instruction files, skills, commands, agents, rules files, settings and an MCP config ({{.Input}}), not files from real repositories. Every release was measured in one job, one after another and taking turns, {{.Runs}} times each after a warm-up scan; the chart shows the median.

The time follows what a release checks: a release with more rules and more agents reads more files and runs more checks on them. Speed-ups show as drops. All points come from the same runner, so they compare with each other; the next run, after the next release, measures them all again. Hover a point for its value.
